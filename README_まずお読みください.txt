デリくらべ：公開メニュー価格の自動取得・比較 準備版
更新：2026-10-08
====================================================

【今回追加した機能】
・利用者提供の富士宮市14店舗をそのまま保持
・「公開メニュー価格」画面：店舗を選び、公開元が許可したメニューページ/フィードの価格を取得
・公開価格を提供元ごと（自社／出前館／Uber Eats／ロケットナウ）に分けて表示
・各金額の出典URL、ページ取得日時を表示
・全く同じ商品名が複数の方法で一致したときだけ「商品単価」を比較
・配達料、手数料、割引、会員条件が不明な場合は支払総額と混同せず表示
・「公開価格を調べる」ボタンで、連携先設定済みなら取得を開始
・取得できない理由（情報源未登録／接続失敗／価格記載なし）を表示
・従来の料金見積API接続口、端末内の店舗編集、手入力比較を継続

【現状の制限：必ずご確認ください】
・実際の出前サービス料金やメニュー価格はまだ取得できていません。
・14店舗の公開価格情報源は未登録です。sourceファイルは空欄です。
・各出前サービスの公式API契約、許可された公式データ提供が未接続です。
・公開された商品価格を取得できても「現在配達できる」「最終総額が安い」とは断定できません。
・出前館・Uber Eats・ロケットナウが個別店舗に対応するかも未確認です。
・本アプリは各出前サービスの運営元と提携していません。

【GitHub Pagesにアプリを反映する】
1. 「index.html」をGitHubの yusuke1534/delikurabe-app のリポジトリ直下へ配置
2. Settings > Pages > Deploy from a branch > main / (root)
3. GitHub Pagesで表示が更新されるまで待つ
注意：GitHub Pagesだけでは、外部サイトから許諾済み価格データを取得するサーバー機能は提供できません。

【自動価格取得の接続手順：次の開発段階】
1. 店舗と各サービスから、公開メニュー情報の自動利用について条件を確認する
2. 自動取得を許可されたURLを server/api/public-price-sources.json に登録する
3. 別のHTTPSホスティング（Node.jsが起動できるサービス）にserverをデプロイする
4. 公開価格サーバーのURLをアプリの「店舗管理 > 公開価格取得サーバー」に入力
   もしくは index.html の PUBLIC_PRICE_API_DEFAULT に全利用者向けURLを設定
5. 「公開価格を調べる」を押すと、許可された公開価格データを読み込む

※ インターネットでの現在の実価格は、各URLと利用条件を検証してから接続します。
※ 今回は勝手にGitHub・サーバー設定・配達サービスの設定を変更していません。
※ 重要：管理画面は端末ローカル編集のみ。全端末共有の管理者認証ではありません。
※ APIキー・パスワード等を index.html やブラウザ設定へ保存しないでください。
